# docker/requirements-prebaked.txt
#
# Stable pure-Python (and nvidia-resiliency-ext) dependencies pre-installed
# into /opt/venv-mbridge at IMAGE BUILD TIME to accelerate runtime `uv sync`.
#
# Design contract
# ---------------
# 1. These packages do NOT depend on /mnt NAS source code (megatron-core and
#    megatron-bridge editable installs are intentionally absent).
# 2. Versions mirror pyproject.toml constraints; do NOT lock to exact versions
#    here — pip resolves latest compatible at image build time.
# 3. Packages provided by the NGC base image (torch, torchvision, triton,
#    transformer-engine, flash-attn, apex, causal-conv1d, mamba-ssm,
#    flash-linear-attention, fla-core, and all nvidia-cuda-* libs) are
#    intentionally absent — they are already present in /opt/venv-mbridge via
#    --system-site-packages and the explicit wheel installs in the Dockerfile.
# 4. install_runtime_deps.sh remains fully backward-compatible: `uv sync`
#    detects that these packages are already installed and skips them, making
#    the runtime step only need to install megatron-core + megatron-bridge.
#
# Maintenance
# -----------
# When pyproject.toml gains new pure-Python dependencies, add them here and
# rebuild the image. When a dependency is removed from pyproject.toml, remove
# it here too. No image rebuild is needed for megatron-core or megatron-bridge
# changes — those are always installed at runtime from /mnt.
#
# nvidia-resiliency-ext is installed from the NVIDIA PyPI index; the Dockerfile
# passes --extra-index-url https://pypi.nvidia.com when invoking pip here.
